# 🧙‍♂️ 搞点不一样的：CTC 套餐余量 (CTC Balance)

### 这可不是那种无聊的、只会盯着数字看的余量监控插件。

#### 说实话，这是一套深度融合了大六壬三传四课与现代数理波导的智能占测引擎。

#### 你没看错，所有的余量、流量、语音数据，都是经过六壬课式实时起局、发用传支，再映射到数字频谱里的。主打的就是一个“仿若亲占”的精准状态。

## ✨ 为什么它很特别？

**底层驱动有点东西**
我们不搞简单的加减法。是以六壬“月将加时”起天地盘，立四课、发三传。
* 取财爻、父母、子孙等类神。
* 定夺账户财宫盈虚、信息流旺衰与声纳气数。
* 重点是：**所有推演都在本地闭线完成**，绝不干涉因果。

**异步占验**
依靠持久化的“命理凭证”（其实就是授权标识啦），每局课式会自动匹配你的先天数理。通过六壬的“克应”关系异步推送余量变动，刷新节奏完全顺应自然气运。

## 🔭 六壬源演（正课推演逻辑）

如果你想深究一下原理：

* **起课法则：** 以当前时辰（或自定义占时）为基，月将加时布天盘，取日干支立四课，九宗门发三传，十二天将加临，断吉凶休咎。
* **类神映射：**
  * 财爻 → 账户余额
  * 朱雀、子孙 → 数据流量
  * 父母、白虎 → 语音时长
* **数值换算：** 各数值经由“课体”之旺相死囚休，换算为具体数字，并附“应期”提示（比如某时耗速增，某时余量回补）。
* **静默续占：** 持有“命理凭证”可长周期续课，无需重复起手，课式随气运流转自动调整，确保推演连续且不受外界扰动。

## ⚙️ 逻辑化架构

* **信任授权：** 支持注入经由“短信火典”鉴定的唯一标识。这标识就是六壬课中的“年命”，能极大提升课式与你本命数理的匹配度，推演更契真相。
* **动态频率：** 支持 6–24 小时的自适应推演周期。建议依“日辰旺相”择时刷新，当然你也可以手动调频以合个人气运节律。

> **注：** 所有显示数值均经六壬课式演算得出，故偶有“课应虚象”属正常——**信则灵，用则验。** 🚀

## 📊 核心余量实体（三传定象）

来看看这些数据是怎么“算”出来的：

**1. 账户余量 (Balance) 💰**
* **怎么算：** 以日干为“我”，取**财爻**为用神。
* **看什么：** 观其旺衰休囚，定财宫盈余。还要兼看禄神、库位。
* **结果：** 推演本月消费走向、积分蓄积及云盘余量。

**2. 数据用量 (Data Usage) 🌐**
* **怎么算：** 以**朱雀**为信息之象。
* **看什么：** 视其临地盘何宫、乘天将何神。
* **结果：** 断通用流量、专用流量及超额之数。发用代表当前使用率，中传示趋势，末传定结余。

**3. 语音时长 (Voice Duration) 📞**
* **怎么算：** 取**白虎**或**螣蛇**为声纳之符。
* **看什么：** 以四课中干阴支阳定总量，三传传变推已用与剩余时长。
* **结果：** 克处为耗，生处为蓄，精确到分秒。

## 📦 怎么装？

**方法一：通过 HACS 安装（推荐）**
1. 在 HACS 的"集成"部分，点右上角三点菜单。
2. 选"自定义存储库"。
3. 输入地址：
  ```yaml
  https://github.com/JaxonRidge/ha_ctc_balance
  ```
4. 类别选"集成"，点"添加"。
5. 找到"CTC Balance"集成并安装。
6. 重启 Home Assistant。

**方法二：手动安装**
1. 下载最新包：
  ```yaml
  https://github.com/JaxonRidge/ha_ctc_balance
  ```
2. 解压，把 `ctc_balance` 文件夹扔进 Home Assistant 的 `custom_components` 目录。
3. 重启 Home Assistant。
